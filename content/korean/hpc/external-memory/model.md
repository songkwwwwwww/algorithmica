메모리 집약적 알고리즘의 성능을 추론하기 위해서는 값비싼 블록 I/O 작업에 더 민감하면서도, 여전히 유용할 만큼 너무 엄격하지 않은 비용 모델을 개발해야 합니다.

### 캐시 인식 모델 (Cache-Aware Model)

[표준 RAM 모델](/hpc/complexity)에서는 기본 작업이 완료되는 시간이 서로 다르다는 사실을 무시합니다. 가장 중요한 점은 서로 다른 유형의 메모리에 대한 작업을 구분하지 않는다는 것인데, 실시간으로 약 ~50ns가 걸리는 RAM 읽기와 약 ~5ms(약 $10^5$배 차이)가 걸리는 HDD 읽기를 동일하게 취급합니다.

이와 비슷한 취지로 *외부 메모리 모델(external memory model)*에서는 I/O 작업이 아닌 모든 작업을 단순히 무시합니다. 구체적으로, 우리는 캐시 계층 중 한 수준을 고려하며 하드웨어와 문제에 대해 다음과 같이 가정합니다.

- 데이터셋의 크기는 $N$이며, 모두 *외부* 메모리에 저장됩니다. 외부 메모리는 단위 시간당 $B$개의 요소로 구성된 블록 단위로 읽고 쓸 수 있습니다(전체 블록을 읽는 것과 단 하나의 요소를 읽는 데 걸리는 시간은 같습니다).
- *내부* 메모리에는 $M$개의 요소를 저장할 수 있습니다. 즉, 최대 $\left \lfloor \frac{M}{B} \right \rfloor$개의 블록을 저장할 수 있습니다.
- I/O 작업만 고려합니다. 읽기와 쓰기 사이에 수행되는 모든 계산은 비용이 0입니다.
- 추가로 $N \gg M \gg B$라고 가정합니다.

이 모델에서 알고리즘의 성능은 실행 중에 외부 메모리에서 읽거나 쓴 총 블록 수인 *I/O 작업(I/O operations)* 또는 *IOPS* 단위로 측정합니다.

우리는 주로 내부 메모리가 RAM이고 외부 메모리가 SSD 또는 HDD인 경우에 집중할 것입니다. 하지만 우리가 개발할 기본 분석 기술은 캐시 계층의 모든 레이어에 적용 가능합니다. 이러한 설정에서 합리적인 블록 크기 $B$는 약 1MB이고, 내부 메모리 크기 $M$은 보통 수 기가바이트이며, $N$은 최대 수 테라바이트입니다.

### 배열 스캔 (Array Scan)

<!-- 외부 메모리 모델은 단순함을 희생하지 않고도 매우 효율적으로 사용될 수 있습니다. -->

간단한 예로, 배열의 요소를 하나씩 반복하며 합계를 계산할 때, 우리는 암시적으로 $O(B)$ 크기의 청크 단위로 데이터를 로드합니다. 외부 메모리 모델의 관점에서는 이러한 청크들을 하나씩 처리하는 것과 같습니다.

$$
\underbrace{a_1, a_2, a_3,} _ {B_1}
\underbrace{a_4, a_5, a_6,} _ {B_2}
\ldots
\underbrace{a_{n-3}, a_{n-2}, a_{n-1}} _ {B_{m-1}}
$$

따라서 외부 메모리 모델에서 합계 계산 및 기타 선형 배열 스캔의 복잡도는 다음과 같습니다.

$$
SCAN(N) \stackrel{\text{def}}{=} O\left(\left \lceil \frac{N}{B} \right \rceil \right) \; \text{IOPS}
$$

외부 배열 스캔을 다음과 같이 명시적으로 구현할 수 있습니다.

```c++
FILE *input = fopen("input.bin", "rb");

const int M = 1024;
int buffer[M], sum = 0;

// 파일이 모두 처리될 때까지
while (true) {
    // 입력 스트림에서 4바이트 요소 최대 M개를 읽음
    int n = fread(buffer, 4, M, input);
    //  ^ 실제로 읽은 요소의 수

    // 더 이상 읽을 요소가 없으면 종료
    if (n == 0)
        break;
    
    // 메모리 내에서 요소들의 합계 계산
    for (int i = 0; i < n; i++)
        sum += buffer[i];
}

fclose(input);
printf("%d\n", sum);
```

대부분의 경우 운영 체제가 이러한 버퍼링을 자동으로 수행한다는 점에 유의하세요. 일반 파일에서 표준 입력으로 데이터가 리디렉션될 때도 운영 체제는 스트림을 버퍼링하고 (기본적으로) 약 4KB의 블록 단위로 읽어옵니다.
