---
title: 프로세스 (Processes)
weight: 1
---

프로세스는 세밀한 제어가 필요할 때 유용합니다.

fork() 시스템 콜은 자식 프로세스(child process)라고 불리는 새로운 프로세스를 생성하며, 이 프로세스는 fork()를 호출한 프로세스(부모 프로세스, parent process)와 동시에 실행됩니다. 새로운 자식 프로세스가 생성된 후, 두 프로세스는 fork() 시스템 콜 다음에 오는 명령어를 실행합니다. 자식 프로세스는 부모 프로세스와 동일한 프로그램 카운터(PC), CPU 레지스터, 열린 파일들을 가집니다.

fork()는 매개변수를 받지 않으며 정수값을 반환합니다. 다음은 fork()가 반환하는 서로 다른 값들에 대한 예시입니다.

```cpp
#include <stdio.h> 
#include <sys/types.h> 
#include <unistd.h> 
int main() { 
    // 이 명령어 이후 동일한 프로그램을 실행하는 
    // 두 개의 프로세스를 생성합니다.
    fork(); 
  
    printf("Hello world!\n"); 
    return 0; 
} 
```

주요 단점은 추가적인 비용입니다. 프로세스는 운영체제에 의해 관리됩니다. 이러한 세밀한 독립성이 필요할 때 별도의 프로세스를 사용합니다.

포크된 프로세스들은 서로의 메모리 공간을 볼 수도, 수정할 수도 없습니다.
